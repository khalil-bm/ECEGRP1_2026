Bienvenue sur mon site coloré

Ce site utilise le CSS (Cascading Style Sheets) pour appliquer des couleurs de fond et de texte. Les couleurs sont définies à l'aide de codes hexadécimaux comme #e74c3c, ce qui permet de choisir parmi plus de 16 millions de possibilités.

Un autre bloc coloré

Vous pouvez facilement modifier la palette en haut du fichier de code dans la section :root. Essayez de remplacer les codes par vos teintes préférées !
